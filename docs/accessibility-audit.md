# Accessibility audit (Phase 8.1)

Target: WCAG 2.2 AA. Audited 2026-10-22 on the built site (home, a project page, the 404) at
1440×900 and 390×844 in Chromium, with the automated checks running in Chromium, Firefox
and WebKit. What is checked by tests stays checked on every push.

## Results

| Area                               | How                                                                                                                                                                                | Result                                                                                                                                                                                                                                                                                                 |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| axe (WCAG 2.2 AA rules)            | `a11y.spec.ts` and per-feature specs (visit panel, timeline, constellation, 404)                                                                                                   | No violations                                                                                                                                                                                                                                                                                          |
| Target size (2.5.8)                | `a11y.spec.ts`: every pointer target is effectively 24×24 (measured, or reached 12 px from its centre), a link in running text, or clear of other targets by a 24 px circle        | Fixed: constellation stars (hit areas 22 → 30 units), landing dots (22 → 24 px), planet labels on phones (16 px tall → invisible 24 px+ hit area), "How to read" summaries, nav links and the phone link. Test fails without the fixes.                                                                |
| Keyboard paths and focus order     | Tabbed through the home page (106 stops)                                                                                                                                           | Logical order: skip link, nav, hero, projects, experience, skills, contact, footer. Every stop shows a `--sol` indicator (project rows outline the whole row). No traps; Escape closes lightbox, visit, playback and popovers. Existing specs cover each widget's keys.                                |
| Focus not obscured (2.4.11)        | Layout review                                                                                                                                                                      | Nothing sticky or fixed covers content (the nav is absolute).                                                                                                                                                                                                                                          |
| Contrast over the sky and canvases | Text hidden (halo kept, transitions off), three frames on the real GPU with the brightest pixel kept, 95th-percentile background per text run, against the text colour and opacity | 190 runs in Experience, Skills, Contact (over the black hole) and the 404 at both sizes: all pass; weakest 5.15 : 1 (timeline sublabels). Slice 2.3 covered the hero, projects and project pages. Two earlier readings below 4.5 were measurement artefacts (colour transitions mid-fade, underlines). |
| Reduced motion                     | Code review of every animation, transition, smooth scroll and `animate()` call; feature specs                                                                                      | All guarded: duration tokens drop to 0, progress tracks hide, smooth scrolls become instant, sky and black hole draw one frame, the camera and playback jump. Fixed: an instant visit could stay "flying" if the explorer was paused when it started (seen on CI); instant moves now finish at once.   |
| Structure (screen-reader proxy)    | DOM review of landmarks, headings, names                                                                                                                                           | One `h1` per page, no skipped heading levels, every section named, landmark navs uniquely labelled, no duplicate ids, `lang="en"`, titles per page. Graphics are `aria-hidden` or labelled groups of buttons whose names start with their visible labels (2.5.3).                                      |
| Reflow (1.4.10)                    | `home.spec.ts`, `projects.spec.ts` at 320 px; 1440 px with the explorer running                                                                                                    | No horizontal page scroll. The timeline and constellation scroll inside their frames (two-dimensional content).                                                                                                                                                                                        |

## Outstanding

- **Screen readers (NVDA on Windows, VoiceOver on macOS / iOS):** not done. No screen reader
  could be driven from the build environment. To check by hand: the hero intro and tour, a
  visit (title focus, tabs, lightbox, back), the timeline (buttons announce pressed state;
  details follow), the constellation (filter, a selection, panel links) and Contact (copy
  feedback is announced politely).
- Real iOS / Android devices: part of 8.3.
