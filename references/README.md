# References

These files are reference data, not application code or agent instructions. Nothing here is served to visitors or imported by the build.

## Approved concept — the visual source of truth

`concept/orbit-concept-v19.html` is the interactive concept approved after 19 reviewed iterations. Open it in a browser (it loads Google Fonts and the files in `concept/media/`). Its values, copy and behavior are written down in `../docs/design-spec.md`; when the two disagree, the spec wins.

`concept/media/` holds the demo screenshots and video used by the landing previews, cropped from the project repositories (Eigenflow `docs/media/`, Exoplanet Transit Lab `docs/assets/`, Quantum Playground `assets/`, Wine Journal `design/prototype-v3/checks/`). Phase 4 copies them into `src/assets/` and `public/media/`. The Wine Journal image is a design prototype and must stay labeled as one.

## Historical

- `stitch/` — the original Google Stitch export (screen, code, design notes). Superseded by the concept; kept for provenance.
- `interaction-studies/explorer-comparison.html` — the early fixed-map vs rotational comparison that led to the rotational explorer.

`manifest.json` records SHA-256 checksums for every file here. Formatting excludes these files so their bytes stay unchanged.
